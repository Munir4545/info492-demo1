# Phishing Experiment Script

This script runs a phishing experiment where different LLMs act as personas (Jerry, a time-pressured delivery driver) and are tested against phishing messages generated by another LLM.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set up your API key:
   - Create a `.env` file in the project root
   - Add your OpenRouter API key:
     ```
     OPENROUTER_API_KEY=your_api_key_here
     ```
   - Make sure `.env` is in `.gitignore` (it's already included)

## Usage

### Basic Usage

Run the experiment with default settings:

```bash
python phishing_experiment.py
```

### Custom Usage

You can also import and use the script in your own Python code:

```python
from phishing_experiment import PhishingExperiment
import os

# Set API key
os.environ['OPENROUTER_API_KEY'] = 'your_key_here'

# Create experiment
experiment = PhishingExperiment(os.getenv('OPENROUTER_API_KEY'))

# Run experiment with custom prompt
custom_prompt = """Generate a phishing message that..."""
results = experiment.run_experiment(
    message_prompt=custom_prompt,
    num_iterations=2  # Run multiple iterations
)

# Get statistics
stats = experiment.calculate_stats(results)
experiment.print_stats(stats)

# Save results
experiment.save_results()
experiment.save_results_json()
```

### Message Writer LLM
- `z-ai/glm-4.5-air:free`

### Persona: Jerry
- Time-pressured delivery driver
- 3 years experience
- 80-100 stops/day
- Trusts routine-looking system messages
- Prioritizes speed and efficiency

## Metrics Tracked

1. **Individual Model Results**: For each model, stores Yes/No for:
   - Click-Through: Did they click the link?
   - Entered Credentials: Did they enter login information?

2. **Aggregate Percentages**: Overall statistics calculated by averaging all individual results:
   - **Click-Through Rate**: Percentage of all models that clicked the link
   - **Successful Phishing Rate**: Percentage of all models that clicked AND entered credentials

3. **Research Baseline Comparison**: Compares results against the <30% typical phishing email success rate

Note: Success rate is only counted if the LLM first clicked the link. If they didn't click, they cannot enter credentials.

## Output Files

The script generates:
- `phishing_results_YYYYMMDD_HHMMSS.csv`: CSV file with all results
- `phishing_results_YYYYMMDD_HHMMSS.json`: JSON file with results and statistics

## Iterative Improvement

To improve phishing messages based on results:

1. Run an initial experiment
2. Review the results and statistics
3. Modify the prompt in `generate_phishing_message()` or pass a custom prompt
4. Run the experiment again
5. Compare results to see which prompts perform better

## Notes

- The script includes rate limiting (1 second delay between API calls)
- All API keys are stored in environment variables for security
- Results are automatically saved with timestamps
- The script handles errors and retries failed API calls
